HOMECARE METRO V1
=================
목적
- 서울·경기·인천 생활설비 사이트의 1차 원본 구조
- 서비스 13종
- 서울 25개 구
- 경기 31개 시·군 + 구가 있는 도시의 구 구조
- 인천 2026-07-01 이후 2군·9구 기준

현재 V1에 들어간 것
1. 메인 디자인
2. 서비스별 메인 페이지
3. 서비스 × 서울/경기/인천 페이지
4. 서울 구 / 경기 시·군·구 / 인천 구·군 상위 페이지
5. services.json / regions.json
6. 기존 사이트 지역 폴더를 읽는 import_regions_from_reference.py

중요
- 동·읍·면 전체 데이터는 '기존에 보유한 지역 사이트 폴더'를 읽어 넣는 방식으로 이어갈 예정입니다.
- SEO 제목/설명/캐노니컬은 아직 최종 적용하지 않았습니다.
- 전화번호, 업체명, 도메인도 아직 넣지 않았습니다.
- 현재는 디자인과 폴더 구조를 먼저 확정하는 단계입니다.

실행
- 압축을 풀고 index.html을 브라우저로 열면 1차 화면 확인 가능
