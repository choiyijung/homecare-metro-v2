HOMECARE METRO V2
=================
서울·경기·인천 동·읍·면 전체 자동 생성 패키지입니다.

실행:
1) 압축 해제
2) RUN-V2-전체지역생성.bat 더블클릭
3) 행정안전부 2026-07-20 주민등록 주소코드 공식 자료 자동 다운로드
4) 서울·경기·인천 읍·면·동을 파싱
5) 서비스 13종 × 전체 지역 페이지 자동 생성
6) data/regions-full-20260720.json / CSV 생성
7) sitemap-paths.txt 재생성

번호 행정동:
역삼1동/역삼2동 -> 역삼동처럼 단순 숫자 행정동은 기본 동명으로 통합합니다.
읍·면은 공식 명칭 그대로 유지합니다.

자동 다운로드가 안 될 경우:
python build_full_regions.py --zip "C:\다운로드\jscode20260720.zip"

현재 단계에서는 최종 SEO를 적용하지 않습니다.
신규 상세페이지는 noindex,follow로 생성됩니다.
